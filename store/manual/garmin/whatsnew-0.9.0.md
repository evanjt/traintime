# Connect IQ "What's new": 0.9.0

Paste each block into the matching language in the Connect IQ Store developer
dashboard. No API exists for this, it is manual.


## English

- New Vibration option in the settings menu, to turn off the app's buzzes.
- The app no longer vibrates when vibration is off in the watch's own settings.

## Deutsch

- Neue Option «Vibration» im Einstellungsmenü, um die Vibrationen der App auszuschalten.
- Die App vibriert nicht mehr, wenn die Vibration in den Einstellungen der Uhr aus ist.

## Français

- Nouvelle option « Vibration » dans le menu des réglages, pour couper les vibrations de l'app.
- L'app ne vibre plus quand les vibrations sont désactivées dans les réglages de la montre.

## Italiano

- Nuova opzione «Vibrazione» nel menu delle impostazioni, per disattivare le vibrazioni dell'app.
- L'app non vibra più quando la vibrazione è disattivata nelle impostazioni dell'orologio.
