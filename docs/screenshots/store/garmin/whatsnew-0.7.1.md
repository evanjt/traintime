# Connect IQ "What's new" — 0.7.1

Paste each block into the matching language in the Connect IQ Store developer
dashboard. No API exists for this, it is manual.


## English

- A delayed train is no longer dropped from tracking a minute after its timetable slot.
- Following a saved route, the final destination line no longer pushes the countdown off small screens.
- If one server is down a second takes over. A version that is too old now asks for an update.

## Deutsch

- Ein verspäteter Zug fliegt nicht mehr eine Minute nach der Fahrplanzeit aus der Verfolgung.
- Auf einer gespeicherten Route schiebt die Zielzeile den Countdown auf kleinen Displays nicht mehr aus dem Bild.
- Fällt ein Server aus, übernimmt ein zweiter. Zu alte Versionen bitten um ein Update.

## Français

- Un train retardé n'est plus retiré du suivi une minute après son horaire.
- Sur un itinéraire enregistré, la ligne de destination finale ne pousse plus le compte à rebours hors des petits écrans.
- Si un serveur tombe, un second prend le relais. Une version trop ancienne demande une mise à jour.

## Italiano

- Un treno in ritardo non viene più tolto dal tracciamento un minuto dopo l'orario previsto.
- Su un percorso salvato, la riga della destinazione finale non spinge più il conto alla rovescia fuori dagli schermi piccoli.
- Se un server non risponde, ne subentra un secondo. Una versione troppo vecchia chiede un aggiornamento.
