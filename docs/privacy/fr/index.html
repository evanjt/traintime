POLITIQUE DE CONFIDENTIALITÉ

Dernière mise à jour : 18 septembre 2026

TrainTime n'a ni compte, ni analyse d'utilisation, ni publicité, ni suivi. Vos coordonnées servent uniquement à trouver les arrêts proches. Elles ne sont jamais écrites dans nos journaux et jamais conservées.

DONNÉES DE LOCALISATION

TrainTime utilise la position de votre appareil pour trouver les arrêts proches. Vos coordonnées :

  • Sont envoyées en HTTPS à notre API (api.traintime.ch), où elles sont comparées à une base d'arrêts tenue en mémoire
  • Servent à cette seule requête, puis sont rejetées. La ligne de requête qui les contient n'est pas écrite dans nos journaux
  • Ne sont jamais transmises à opentransportdata.swiss. Les départs sont récupérés uniquement à partir d'identifiants d'arrêts
  • Votre dernière position connue est mise en cache sur votre appareil pour un démarrage plus rapide

DONNÉES STOCKÉES SUR VOTRE APPAREIL

  • Dernière position connue - pour un démarrage plus rapide quand le GPS n'est pas disponible
  • Mode de transport - le dernier mode choisi (train, bus ou tram)
  • Favoris, arrêts épinglés et réglages - partagés entre téléphone et montre par la liaison propre à la plateforme de la montre
  • Trajets enregistrés et rappels - si vous les utilisez

Aucune autre donnée n'est conservée. Les départs sont récupérés à chaque fois et gardés uniquement en mémoire.

POURQUOI TRAINTIME A SA PROPRE API

Les données des transports publics suisses viennent d'opentransportdata.swiss via des services distincts : OJP 2.0 pour les départs et un service de formation pour la composition des trains. Notre API associe votre position aux arrêts les plus proches, récupère départs et formations, les fusionne en une seule réponse et la met en cache pendant une minute, pour que des milliers de montres n'interrogent pas chacune la source. Elle ne reçoit rien d'autre que les coordonnées et les identifiants d'arrêts dont une requête a besoin. Son code source est public : github.com/evanjt/traintime-api.

SERVICES TIERS

API TrainTime (api.traintime.ch)

  • Hébergement - l'API tourne sur Cloudflare Workers (Cloudflare, Inc., États-Unis) et sur un serveur en Suisse que nous exploitons. Les deux sont accessibles via le réseau de Cloudflare
  • Journaux d'exploitation - pour chaque requête, nous enregistrons le point de terminaison, le statut HTTP, le temps de réponse, si la réponse venait du cache, et un court libellé de la plateforme de l'app. Nous n'enregistrons ni coordonnées, ni adresse IP, ni appareil, ni identifiant d'utilisateur. Cloudflare conserve un échantillon de ces lignes pendant trois jours. Sur notre propre serveur, elles restent dans un petit tampon rotatif qui n'est jamais copié ailleurs
  • Statistiques agrégées - nombre de requêtes par point de terminaison et par plateforme, sans données personnelles
  • Finalité - comprendre l'utilisation, adapter les ressources à la hausse ou à la baisse, détecter les abus comme les attaques par déni de service
  • Cloudflare - en tant que sous-traitant selon son Data Processing Addendum, Cloudflare traite les métadonnées de connexion, y compris votre adresse IP, pour fournir et protéger le service, aux États-Unis et dans les autres pays où Cloudflare opère. Cloudflare, Inc. est certifiée sous le Swiss-U.S. Data Privacy Framework, que le Conseil fédéral reconnaît comme adéquat pour les entreprises certifiées. Les clauses contractuelles types de l'addendum s'appliquent à titre subsidiaire
  • Code source : github.com/evanjt/traintime-api

Open Transport Data Suisse (opentransportdata.swiss)

  • Fournit les horaires, les données en temps réel et les formations. Exploité par CFF Infrastructure pour le compte de l'Office fédéral des transports
  • Ne reçoit que des identifiants d'arrêts. Vos coordonnées ne sont jamais envoyées à ce service
  • Conditions d'utilisation

Les données envoyées par l'app quittent votre appareil vers nous, le développeur, et non vers Apple, Google ou Garmin. Aucun autre service, SDK ou API tiers n'est utilisé. Pas d'analyse d'utilisation, de publicité, de rapports de plantage ni de suivi. Uniquement des comptages agrégés de requêtes, sans données personnelles.

DONNÉES EXTERNES

  • Les informations de transport (arrêts, départs, retards, quais, formations) proviennent d'opentransportdata.swiss et sont fournies en l'état
  • Nous ne contrôlons ni ne garantissons l'exactitude, l'exhaustivité ou la disponibilité de ces données externes
  • Les interruptions ou erreurs de la source sont hors de notre contrôle
  • Source des données : opentransportdata.swiss (attribution exigée par ses conditions d'utilisation)

PARTAGE DES DONNÉES

Vos coordonnées sont envoyées à notre API pour trouver les arrêts proches et rejetées une fois la requête traitée. Les départs sont récupérés uniquement à partir d'identifiants d'arrêts. Les journaux d'exploitation décrits ci-dessus ne contiennent aucune donnée personnelle. Nous ne vendons ni ne partageons de données avec qui que ce soit.

VIE PRIVÉE DES ENFANTS

TrainTime ne collecte de données d'aucun utilisateur, y compris les enfants de moins de 13 ans.

VOS DROITS

  • Droit d'accès : Vous pouvez demander à tout moment si nous traitons des données vous concernant. Nous répondons dans les 30 jours. La réponse sera que le serveur ne détient rien qui puisse vous être rattaché, il n'y a donc rien à exporter ni à effacer de notre côté
  • Consulter vos données : Toutes les données sur votre appareil sont visibles dans l'app
  • Effacer vos données : Désinstallez l'app pour supprimer toutes les données stockées localement
  • Retirer l'accès à la position : Désactivez l'autorisation de localisation à tout moment dans les réglages de l'appareil
